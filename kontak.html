Tanya Jawab

Pertanyaan yang Sering Diajukan

Jawaban transparan seputar arsitektur teknis, metodologi perhitungan emisi, dan keamanan data di platform EcoLoka.

Sama sekali tidak. EcoLoka dibangun 100% sebagai static client-side website murni tanpa backend server database. Seluruh riwayat perhitungan disimpan secara privat pada penyimpanan lokal peramban Anda (*LocalStorage*) dan tidak pernah diunggah ke pihak ketiga manapun.

Perhitungan kami mengacu pada standar faktor emisi rata-rata di Indonesia yang dipublikasikan oleh Kementerian ESDM, KLHK, dan panduan IPCC. Parameter mencakup emisi bensin per kilometer transportasi harian, intensitas karbon jaringan listrik PLN per kWh, serta perkiraan jejak metana dari siklus konsumsi pangan.

EcoLoka dibangun 100% orisinal dari nol tanpa template siap pakai. Seluruh gaya CSS disusun dengan arsitektur modular BEM, dan interaktivitasnya murni menggunakan Vanilla JavaScript modern (ES6+) guna mematuhi secara radikal syarat ketat perlombaan Web Design INVENTION 2026.

Anda dapat mengunjungi halaman Dashboard Pemantauan lalu menekan tombol berwarna merah bertuliskan "Hapus Riwayat", atau Anda dapat menekan tombol "Hitung Ulang" di halaman Kalkulator Aksi Hijau kapan saja.
